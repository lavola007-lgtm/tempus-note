# 템퍼스 관리노트

자기주도 학습관 조교용 학생 관리 웹 앱입니다. 조교가 휴대폰 웹 화면에서 학생의 하루 기록을 입력하면 **구글 시트에 한 줄씩 쌓이고**, 학생별 공부 이력과 학부모 주간 피드백(유미니 정기피드백 입력 순서)을 만들어 줍니다.

**체험판:** https://lavola007-lgtm.github.io/tempus-note/
설치 없이 바로 써 볼 수 있습니다. 체험판의 기록은 그 브라우저에만 저장되고 구글 시트로 가지 않습니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 오늘 | 오늘 수업, 학생별 지난 점검사항·마감 숙제·작성 여부 |
| 기록하기 | 출결·숙제·집중도·자기주도 계획 달성은 버튼으로, 특이사항·다음 점검사항만 글로 |
| 수업일지 | 반 단위 진도·숙제·마감일 |
| 학생 이력 | 누적 기록·순공·집중도·계획 달성률, 주간 피드백 이력, 하루 기록 타임라인 |
| 주간 피드백 | 유미니 정기피드백 순서대로 값 + 항목별 복사, '시트에 저장'으로 주간 이력 누적 |
| 학생·시간표 | 학생·조교 관리, 월별 시간표 (다음 달 복사) |

처음 설치하면 `샘플학생` 1명의 예시 이력이 들어 있습니다. 실제 학생을 추가한 뒤 샘플학생은 '재원' 체크를 끄면 숨겨집니다.

## 구글 시트에 쌓이는 곳

| 시트 탭 | 무엇이 쌓이나 |
|---|---|
| 관리일지 | 학생 1명 × 1일 = 1줄 (같은 날 다시 저장하면 그 줄이 수정됨) |
| 수업일지 | 수업 1회 = 1줄 |
| 주간피드백 | 학생 1명 × 1주 = 1줄 |
| 학생이력 | B1에서 학생을 고르면 그 학생의 하루 기록이 최신순으로 |
| 학생 · 조교 · 시간표 | 설정 |

## 설치 (구글 계정 1개, 약 5분)

1. 빈 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `Code.gs` 내용을 붙여 넣고, **파일 + → HTML** 로 `Index` 를 만들어 `Index.html` 내용을 붙여 넣습니다.
3. **프로젝트 설정 → 매니페스트 표시**를 켜고 `appsscript.json` 내용을 붙여 넣습니다.
4. 함수 `setup` 을 한 번 실행하고 권한을 허용합니다.
5. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: Google 계정이 있는 모든 사용자) → 나온 주소를 조교에게 공유합니다.

명령줄로 설치하려면 [clasp](https://github.com/google/clasp) 를 씁니다.

```bash
clasp login
```
```bash
clasp create-script --title "템퍼스 관리노트" --parentId <구글 시트 ID>
```
```bash
clasp push --force
```
```bash
clasp create-deployment --description "v1"
```

코드를 고친 뒤에는 `clasp push --force` 후 `clasp create-deployment --deploymentId <배포 ID>` 로 같은 주소에 다시 배포합니다.

> 웹 앱 주소를 아는 구글 계정 사용자는 누구나 기록을 저장할 수 있습니다. 주소는 조교에게만 공유하세요.

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 구글 시트 백엔드 (탭 생성, 읽기, 저장·수정·삭제) |
| `Index.html` | 조교용 웹 화면 |
| `appsscript.json` | Apps Script 설정 (한국 시간, 웹 앱 권한) |
| `tests/` | 가짜 스프레드시트로 `Code.gs` 를 돌려보는 테스트 — `node tests/run_test.js` |
| `tools/build-demo.js` | 체험판 `docs/index.html` 만들기 — `node tools/build-demo.js` |
| `docs/` | GitHub Pages 체험판 |
